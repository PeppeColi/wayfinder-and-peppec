# Notes

A command-line tool for one person to take notes from the terminal, tag them, and find them again.

## Language

**Note**:
A piece of text saved by the user, with the instant it was created and zero or more tags.
_Avoid_: Entry, memo, record

**Tag**:
A short label attached to a note, used to find it again. Tags that differ only in capitalisation are the same tag.
_Avoid_: Label, category, keyword

**Notebook**:
All the notes of the user, taken together. There is exactly one.
_Avoid_: Store, database, collection

**Export**:
A copy of the notes written to a file the user chooses.
_Avoid_: Dump, backup
